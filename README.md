# CCDPS brand kit

Logo, pictogram, favicons and design tokens for CCDPS, generated by a Go
program from two sources: the pictogram SVG `assets/ccdps-mark-v3.svg` and the
Figtree 700 outlines in `fonts/`. The output is committed under `kit/`; CI
regenerates it and fails if it drifts.

```
go run ./cmd/brandkit generate          # writes kit/
go run ./cmd/brandkit check             # verifies kit/ (sizes, no <text>, files < 1 MiB)
```

## What is in `kit/`

| file | use |
|---|---|
| `mark-{colour,inverse,white,black}.svg` | pictogram master, 256 x 256 viewBox |
| `lockup-horizontal-{colour,inverse,white,black}.svg` | pictogram + wordmark + baseline, 919.3 x 256 viewBox, all text as outlines (no `<text>`) |
| `favicon.svg`, `favicon.ico` (16/32/48) | browser tab; small cut (below) |
| `apple-touch-icon.png` (180), `avatar-512.png` | opaque, square corners: the platform applies its own mask |
| `mark-{16,32,64,128,256,512,1024}.png` | pictogram rasters |
| `saml-logo-{160,80}.png` | identity-provider tiles |
| `lockup-{colour,inverse}-{600,1200,2400}.png` | lockup rasters, transparent |
| `social-banner-1280x640.png` | social preview, inverse lockup on #121212 |
| `tokens.json` | colours, geometry, minimum sizes |

Variants: `colour` (dark tile, white strokes, dark wordmark, for light
backgrounds), `inverse` (white tile, dark strokes, white wordmark, for dark
backgrounds), `white` and `black` (one colour; the strokes are cut out of the
tile with a mask, so the background shows through).

## Usage rules

- Clear space: 6 x the stroke width (48 units of the 256-unit tile, 18.75 % of
  the tile height) on every side. The original lockup leaves about 5.75 x its
  stroke between tile and wordmark; 6 is the rounded rule.
- Minimum size: pictogram 16 px (32 px recommended; at 16 px the strokes are
  about one pixel wide), lockup 470 px wide (below that the
  baseline caps are under 7 px; use the pictogram alone).
- Small cut: rasters of 48 px and below (16, 32, ICO, `favicon.svg`) use stroke
  width 10 instead of 8. The strokes 163 and 177 are 14 units apart, so 10 is
  the thickest cut that keeps a gap.
- Do not stretch, rotate, recolour outside the four variants, add effects, or
  set the wordmark in another font. Use the SVG, not a re-typed name.

## Provenance and measurement

The artwork was redrawn from two low-resolution screenshots of the existing
logo, whose vector original and font are not available. The screenshots are not
in this repository (unknown rights); `docs/measurements.md` holds the numbers
derived from them and how they were obtained. In short:

- Wordmark: 51 free fonts were fitted to the five letters; Figtree 700 scored
  mean glyph IoU 0.910 (rank 2; rank 1 scored 0.920). A positive control (a
  known font rendered and re-fitted) recovers its own em to 0.002 px.
- Pictogram: the first redraw scored IoU 0.817; the fitted v3 scores 0.974 (ceiling
  0.981), chamfer 0.024 px, 0.9655 on a held-out 2x upscaling.
- This is a redraw, not the original artwork. The lockup tile is square where the
  original is 127 x 117 px. The baseline "CENTRE DE CALCUL ET DE DONNÉES DU
  PLATEAU-DE-SACLAY" is Figtree 700 capitals as outlines, placed at the measured
  rows (letters 25..83, baseline text 105..112 of a 117 px tile) and
  letter-spaced (0.0315 em) so its ink spans the wordmark's ink. Its flat cap
  height is 13.74 units: 9.0 px in the 600 px lockup, 17.9 px at 1200, 35.9 px
  at 2400.

`cmd/logofit` reproduces the measurements given the screenshots
(`logofit run --lockup L --mark M`, `logofit trace --mark M`, `logofit measure --lockup L`).

## Portability of the check

PNG output depends on float arithmetic (arm64 fuses multiply-add, amd64 does
not), so CI compares regenerated PNGs pixel by pixel with a tolerance of 3 per
channel and SVG/JSON byte for byte.
